# コンポーネント設計ガイド

## ディレクトリ構造
```
components/
├── forms/      # フォーム関連コンポーネント
├── layouts/    # ページレイアウトコンポーネント
├── sections/   # ページセクションコンポーネント 
└── ui/         # 汎用UIコンポーネント
```

## 設計原則
1. **単一責務の原則**
   - 1コンポーネント=1機能
   - 再利用可能な最小単位で設計
   - 状態管理は親コンポーネントに委譲

2. **型安全性の確保**
   ```tsx
   interface ButtonProps {
     variant?: 'primary' | 'secondary';
     size?: 'sm' | 'md' | 'lg';
     children: React.ReactNode;
   }
   ```

3. **スタイリング規則**
   - Tailwind CSSを採用
   - カスタムクラスは`@/lib/design-system`で管理
   - レスポンシブ対応を基本とする

4. **ドキュメント化**
   - コンポーネント使用例を`.demo.tsx`に実装
   - Props説明をJSDocで記載
   ```tsx
   /**
    * 汎用ボタンコンポーネント
    * @param variant - ボタンのスタイルバリアント
    * @param size - ボタンのサイズ
    */
   ```

## 実装ガイドライン
1. **フォームコンポーネント**
   - バリデーション処理を分離
   - エラーハンドリングを統一
   - アクセシビリティ対応

2. **レイアウトコンポーネント**
   - ページ全体の構造を定義
   - ナビゲーションとフッターを包含
   - レスポンシブ対応を基本

3. **UIコンポーネント**
   - スタイルバリアントをpropsで制御
   - アニメーション効果を標準化
   - アイコンはSVGスプライトで管理

4. **セクションコンポーネント**
   - ページ固有のセクションを実装
   - ストーリーブックで状態管理
   - データ取得処理は含まない
